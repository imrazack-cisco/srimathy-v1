# SRIMATHY

Offline-First Autonomous Multi-Agent Educational AI Platform

## Features

- Offline AI using Ollama
- Gemma 3 4B
- Multi-Agent Architecture
- Runtime Dashboard
- Health Monitoring
- Zero API Cost

## Installation

```bash
git clone https://github.com/imrazack-cisco/srimathy-v1.git

cd srimathy-v1

npm install
```

Install Ollama

```bash
ollama pull gemma3:4b

ollama serve
```

Run the project

```bash
npm run dev
```

Open

http://localhost:3000
